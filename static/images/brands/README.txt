Drop real brand logo PNGs in this folder to replace the text placeholders
on the Home page's scrolling brand strip.

File name must be the brand name in lowercase, e.g.:
  vivo.png
  oppo.png
  iphone.png
  samsung.png
  oneplus.png
  realme.png
  iqoo.png
  tecno.png
  itel.png
  infinix.png
  moto.png
  lava.png

Use a transparent-background PNG, roughly 200x80px, for the cleanest look.
